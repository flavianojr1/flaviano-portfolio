# 🌐 Flaviano Astolfo Junior — Portfolio

Portfólio pessoal e profissional desenvolvido com **Next.js 15**, **React 19**, **TypeScript** e **Tailwind CSS**, apresentando projetos, competências e trajetória técnica em **Data Analytics**, **Business Intelligence** e **Automação**.

---

## 🚀 Tecnologias e Ferramentas

- **Frontend & Core:** Next.js (App Router), React 19, TypeScript
- **Estilização & Animações:** Tailwind CSS, Lucide Icons, Motion (Framer Motion)
- **Domínio & Especialidades:** SQL Server (T-SQL), Python (Pandas, ETL), Power BI (DAX, Star Schema), Automação de Processos

---

## ✨ Funcionalidades

- 🌐 **Suporte Bilíngue:** Alternância em tempo real entre Português (PT-BR) e Inglês (EN-US).
- 📱 **Design Responsivo & Moderno:** Interface otimizada para desktops, tablets e smartphones com modo escuro/claro nativo.
- 📊 **Showcase de Projetos:** Apresentação detalhada com problema, solução técnica, stack e links para código-fonte.
- ⚡ **Performance & SEO:** Estrutura otimizada com Next.js Server & Client Components para máxima velocidade de carregamento.

## 🛠️ Como Executar Localmente

### Pré-requisitos
- [Node.js](https://nodejs.org/) (versão 18.18+ recomendada)
- `npm` ou `yarn` ou `pnpm`

### Instalação

1. Clone o repositório:
```bash
git clone https://github.com/flavianojr1/flaviano-portfolio.git
cd flaviano-portfolio
```

2. Instale as dependências:
```bash
npm install
```

3. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

4. Abra no navegador: [http://localhost:3000](http://localhost:3000)
